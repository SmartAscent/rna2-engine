# RNA2 Package Manager & Memory Engine (rna2_pm)
Developed by **SmartAscent Labs**

RNA2 is an embedded domain-specific archive and execution layer designed for binary state management, encrypted block packaging, and low-latency C-ABI interoperability.

## Architecture & Features

* **High-Performance Core:** Built in Rust (rna2_pm.dll / rna2_pm.lib).
* **Encryption & Compression:** AES-256-GCM hardware-accelerated encryption combined with flate2 zlib compression.
* **C-ABI Foreign Function Interface (FFI):** Native binding support for Python, C/C++, C#, Node.js, and Go.
* **Multi-Language Bindings:** High-level Python bridge via rna2_engine.py.
